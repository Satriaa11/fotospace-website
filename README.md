# fotospace-website

Website promosi **Foto Space** — aplikasi upload otomatis foto & video ke FotoYu untuk fotografer event.

Stack: Astro 7 (static) · React islands · Tailwind CSS v4 · Remotion (produksi video di `videos/`) · Cloudflare Pages.

## Dokumen

- **Aturan pengerjaan:** [AGENTS.md](./AGENTS.md) — wajib dibaca sebelum menyentuh kode
- **Rencana & milestone:** [docs/plans/PLAN-Website-FotoSpace.md](./docs/plans/PLAN-Website-FotoSpace.md)

## Pengembangan

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
npm run check    # astro check (TypeScript)
npm run lint     # eslint
```
